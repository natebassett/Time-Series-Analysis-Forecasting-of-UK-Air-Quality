# Time Series Analysis & Forecasting of UK Air Quality

## Overview
This project explores historical UK air quality data using time series analysis and forecasting techniques in R. The aim was to analyse long-term trends, seasonality, and predict future pollutant behaviour through statistical modelling and visualisation.

## Technologies Used
- R
- Forecast Package
- ggplot2
- dplyr
- lubridate
- tidyr
- vroom

## Features
- Data cleaning and preprocessing
- Time series decomposition
- Trend and seasonal analysis
- Forecast modelling
- Interactive visualisation concepts
- Presentation of findings through statistical plots and forecasting outputs

## Dataset
UK Air Quality monitoring data sourced from AURN/OpenAQ datasets.

## Repository Contents
- `.R` analysis file
- Presentation slides
- Supporting visualisations and outputs
